
# Fashion E-Commerce Website (Frontend)

# You can have a view of the website at
https://madhura-sarkar.github.io/Fashion-Website/

This project is a front-end design of a fashion e-commerce website built by our team. The website allows users to browse fashion items, add them to their cart, wishlist, and simulate a checkout experience. It also includes profile management features for registered users.

## Features

- **User Wishlist**: Users can add fashion items to their wishlist for future reference.
- **Add to Cart**: Users can add items to their shopping cart.
- **Search Functionality**: Users can search for items by keywords and categories.
- **Payment Page**: Simulated payment page where users can complete their checkout process.
- **Profile Management (Frontend Only)**: Users can edit their profile image and personal information.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Framework**: Bootstrap5
- **Responsive Design**: Ensures the website is mobile-friendly.
